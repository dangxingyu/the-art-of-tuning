A handbook for nuisance hyperparameters

The Art of Tuning

This handbook collects practical tuning moves for optimizer and training-recipe work: coordinate descent, run reading, budgeted sweeps, transfer priors, and literature grounding.

The intended format is a field guide. Each chapter names a move, explains when to use it, gives the operating protocol, and records the caveats a later tuning campaign needs.

Scope: this handbook is about nuisance tuning. Scientific coordinates such as scale, data mixture, model family, and training horizon belong primarily in a scaling ladder; this handbook tunes the recipe so that setting receives a fair measurement.

Operating stance

Working Principles

  • Tune one clear objective at a time.
  • Treat scientific coordinates as outer-loop questions; tune nuisance coordinates so each setting gets a fair measurement.
  • Move only one accepted coordinate per coordinate-descent round.
  • Know the noise scale before trusting a gain, and keep `epsilon` above that scale.
  • Use parallelism across recipe families first when a single campaign would over-saturate coordinate-level parallelism.
  • Let the ledger prune the grid: recenter, narrow, expand on boundaries, and defer silent coordinates.
  • Read literature as a prior over coordinates, not as an answer.
  • Preserve the exact job recipe, result path, and stop reason.
