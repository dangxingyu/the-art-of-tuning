Tune Recipes, Not The Scientific Question

The handbook assumes the scientific setting has already been chosen: model family, scale, data, batch size, horizon, and broad optimizer family. The campaign tunes the nuisance coordinates inside that setting so the result is not dominated by a stale learning rate, a mis-set timescale, or a bad default.

Source Cards Before Jobs

Literature grounding spends no compute, but it changes the first grid. The useful unit is a claim with regime, coordinate, confidence, and caveat.

claim

What the paper says.

regime

Where it was measured.

coordinate

Which nuisance knob it informs.

confidence

Narrow grid, medium grid, wide grid, or do not transfer.

caveat

What would make the claim stop applying.
